# Sterling Search Intelligence

An enterprise-grade SEO, AEO (Answer Engine Optimization), and GEO (Generative Engine Optimization) analytics and visibility platform for the Sterling Holidays resort portfolio.

## Features

- **SEO Intelligence**: Search engine rankings, technical health monitoring, keyword performance, and competitor bench-marking.
- **AEO Intelligence**: Answer engine FAQ coverage, structured answer readiness, and voice/assistant search tracking.
- **GEO Intelligence**: AI mentions (ChatGPT, Perplexity, Gemini, Claude), AI visibility scores, and citation gap analysis.
- **Resort Analytics**: Property-level performance tracking across Sterling Holidays destination resorts.
- **Automated Recommendations**: Actionable optimization steps for marketing and SEO teams.

## Tech Stack

- **Framework**: TanStack Start & TanStack Router
- **UI Library**: React 19, Tailwind CSS v4, Lucide Icons, Recharts
- **Type Safety**: TypeScript & Zod
- **State Management**: TanStack React Query

## Local Development

Ensure you have Node.js (v20+) installed.

```sh
npm install
npm run dev
```

## Production Build & Netlify Deployment

```sh
npm run build
npm run preview
```

The output build directory `.output/public` is pre-configured for seamless deployment to Netlify.
